# GitHub Sponsors Configuration

## Tiers

### Tier 1: Supporter ($5/month)
- Name in README sponsors section
- Access to sponsors-only Discord channel
- Early access to release notes

### Tier 2: Backer ($25/month)
- Everything in Supporter
- Logo in README (small)
- Priority issue response (48h)

### Tier 3: Silver Sponsor ($100/month)
- Everything in Backer
- Logo in README (medium) + docs site footer
- Monthly office hours call (30min)
- Feature request priority

### Tier 4: Gold Sponsor ($500/month)
- Everything in Silver
- Logo on docs homepage
- Dedicated support channel
- Custom plugin development guidance
- Quarterly architecture review

### Tier 5: Enterprise Sponsor ($2,000/month)
- Everything in Gold
- Logo prominently on homepage + all docs pages
- Direct Slack/Discord channel with maintainer
- Custom feature development (up to 10h/month)
- Production deployment support
- Published case study

## One-time Donations
- $10 — Thank you mention
- $50 — Name in release notes
- $200 — 1-hour architecture consultation
- $1,000 — Half-day workshop/training session
