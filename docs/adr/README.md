# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for ReactiveBase.

## What is an ADR?

An ADR is a short document that captures an important architectural decision made along with its context and consequences.

Use [000-template.md](000-template.md) when creating new ADRs.
