# @reactivebase/cli

ReactiveBase CLI — dev server, type generation, and database migrations.

## Installation

```bash
npm install -D @reactivebase/cli
```

## Usage

```bash
# Start the development server
npx reactivebase dev

# Generate TypeScript types from your schema
npx reactivebase generate

# Run database migrations
npx reactivebase migrate --generate
npx reactivebase migrate --apply
```

## Documentation

Full documentation is available at [reactivebase.dev/docs](https://reactivebase.dev/docs).
