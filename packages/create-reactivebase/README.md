# create-reactivebase

Scaffold a new ReactiveBase project with an interactive wizard.

## Usage

```bash
# Interactive wizard
npx create-reactivebase my-app

# Skip wizard, use defaults
npx create-reactivebase my-app --yes

# Use SaaS template
npx create-reactivebase my-app --template saas
```

## Documentation

Full documentation is available at [reactivebase.dev/docs](https://reactivebase.dev/docs).
